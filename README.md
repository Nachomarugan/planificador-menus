# Planificador de menús

Webapp sencilla para organizar el menú semanal familiar, mantener una lista de la compra y consultar recetas.

## Versión actual

- Menú semanal con comida del comedor, comida en casa y cena.
- Lista de la compra editable.
- Recetario con detalle de ingredientes y preparación.
- Diseño adaptable a móvil.

Los datos se guardan en el navegador. La sincronización entre dispositivos mediante Supabase está pendiente de configurar.

## Publicación

El proyecto es una web estática y no necesita un paso de compilación. Se puede importar en Vercel desde este repositorio con el directorio raíz como salida.
